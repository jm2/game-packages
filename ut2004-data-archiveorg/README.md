# ut2004-data-archiveorg

Game data for Unreal Tournament 2004: Editor's Choice Edition, unpacked from
the ECE DVD image that OldUnreal hosts (files.oldunreal.net, the same image
as on archive.org) and installed to /opt/ut2004. Play it with the native
OldUnreal binaries from ut2004-bin.

## Notes

The DVD image is about 3 GB; with the unpacked cabinets, the game tree and the
finished package the build needs about 15 GB of free space. Only the English language
groups are installed, as with OldUnreal's own installer.
