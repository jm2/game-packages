# dungeondefenders-hib

Dungeon Defenders (native Linux) with data via Humble Bundle

Run it with `dungeondefenders` or from the desktop menu.

## Building

Place these files next to the build files or in
`${TMPDIR:-/var/tmp}/linux-packages-cache/dungeondefenders-hib/` before building:

- `dundef-linux-03052013.mojo.run` - Humble Bundle
