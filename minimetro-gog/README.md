# minimetro-gog

Mini Metro, the minimalist subway layout game by Dinosaur Polo Club, from the
DRM-free Linux installer on GOG.

Run it with `minimetro` or from the desktop menu.

## Building

Place these files next to the build files or in
`${TMPDIR:-/var/tmp}/linux-packages-cache/minimetro-gog/` before building:

- `mini_metro_202609291145_release_57_94756.sh` - GOG (lgogdownloader: mini_metro/en3installer0)

## Notes

GOG's Linux installer for release-57 (build 202609291145, 228589568 bytes).
Fetch it with `tools/fetch-gog minimetro-gog` (lgogdownloader), or download it
from GOG (`mini_metro_202609291145_release_57_94756.sh`).

Settings and saves live in `~/.config/unity3d/Dinosaur Polo Club/Mini Metro/`.
