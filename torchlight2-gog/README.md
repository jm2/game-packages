# torchlight2-gog

Torchlight II (native Linux) with data via GOG

Run it with `torchlight2` or from the desktop menu.

## Building

Place these files next to the build files or in
`${TMPDIR:-/var/tmp}/linux-packages-cache/torchlight2-gog/` before building:

- `gog_torchlight_2_2.0.0.2.sh` - GOG (lgogdownloader: torchlight_ii/en3installer2)
