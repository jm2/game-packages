# doom3bfg-data-gog

Doom 3 BFG Edition data via GOG

## Building

Place these files next to the build files or in
`${TMPDIR:-/var/tmp}/linux-packages-cache/doom3bfg-data-gog/` before building:

- `setup_doom3_bfg_edition_1.14_20230201_(62122).exe` - GOG (lgogdownloader: doom_3_bfg_edition_game/en1installer0)
- `setup_doom3_bfg_edition_1.14_20230201_(62122)-1.bin` - GOG (lgogdownloader: doom_3_bfg_edition_game/en1installer1)
- `setup_doom3_bfg_edition_1.14_20230201_(62122)-2.bin` - GOG (lgogdownloader: doom_3_bfg_edition_game/en1installer2)
