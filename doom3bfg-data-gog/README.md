# doom3bfg-data-gog

Doom 3 BFG Edition data via GOG

## Building

Place these files next to the build files or in
`${TMPDIR:-/var/tmp}/linux-packages-cache/doom3bfg-data-gog/` before building:

- `setup_doom_3_bfg_1.14_(13452).exe` - GOG (lgogdownloader: doom_3_bfg_edition_game/en1installer0)
- `setup_doom_3_bfg_1.14_(13452)-1.bin` - GOG (lgogdownloader: doom_3_bfg_edition_game/en1installer1)
