# revolt-data-revoltio

The original Re-Volt (1999) game files (tracks, cars, graphics and sounds),
downloaded at build time from Re-Volt I/O, the community site that hosts them
for RVGL Launcher, and installed as RVGL's game_files pack in
/opt/rvgl/packs/game_files. Play it with rvgl-bin.

## Notes

Re-Volt I/O hosts these files "for the sake of game preservation": the game
is abandonware, its rights belong to WeGo Interactive, and there is no
license to redistribute it. This package is built locally from their
download, as RVGL Launcher does; if you own the game on Steam,
revolt-data-steam builds the same pack from your copy.

The download URL is not versioned: when Re-Volt I/O publishes a new
game_files version (see https://distribute.re-volt.io/packages.json) the
checksum stops matching and this package needs an update.
