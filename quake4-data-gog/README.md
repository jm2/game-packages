# quake4-data-gog

Quake 4 data via GOG

## Building

Place these files next to the build files or in
`${TMPDIR:-/var/tmp}/linux-packages-cache/quake4-data-gog/` before building:

- `setup_quake_iv_1.4.3_lang_update_(63131).exe` - GOG (lgogdownloader: quake_4_game/en1installer0)
- `setup_quake_iv_1.4.3_lang_update_(63131)-1.bin` - GOG (lgogdownloader: quake_4_game/en1installer1)
