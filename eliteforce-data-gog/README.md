# eliteforce-data-gog

Star Trek Voyager: Elite Force data via GOG

## Building

Place these files next to the build files or in
`${TMPDIR:-/var/tmp}/linux-packages-cache/eliteforce-data-gog/` before building:

- `setup_star_trek_voyagertm_elite_force_1.2_(34378).exe` - GOG (lgogdownloader: star_trek_voyager_elite_force/en1installer0)
