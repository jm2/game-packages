# broforce-gog

Broforce (native Linux) with data via GOG

Run it with `broforce` or from the desktop menu.

## Building

Place these files next to the build files or in
`${TMPDIR:-/var/tmp}/linux-packages-cache/broforce-gog/` before building:

- `broforce_forver_hf_linux_71321.sh` - GOG (lgogdownloader: broforce/en3installer0)
