# rvgl-soundtrack

The original Re-Volt soundtrack (based on the Dreamcast version) as Ogg
Vorbis files, installed as RVGL's soundtrack pack in
/opt/rvgl/packs/soundtrack and downloaded at build time from Re-Volt I/O.

## Notes

The music is part of Acclaim's Re-Volt and is hosted by Re-Volt I/O without
a license to redistribute it. The download URL is not versioned: when a new
soundtrack pack is published the checksum stops matching.

The soundtrack pack is loaded after the game data, so it also replaces any
music that came with revolt-data-steam.
